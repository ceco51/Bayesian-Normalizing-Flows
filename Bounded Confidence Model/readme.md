## Modified Bounded Confidence Model

The synthetic datasets and corresponding posterior estimates are organized as follows:

- `data1.csv` — Synthetic observations for Group 1  
- `posterior1.csv` — Estimated posterior distribution corresponding to Group 1  

- `data2.csv` — Synthetic observations for Group 2  
- `posterior2.csv` — Estimated posterior distribution corresponding to Group 2  

- `data3.csv` — Synthetic observations for Group 3  
- `posterior3.csv` — Estimated posterior distribution corresponding to Group 3  

- `data4.csv` — Synthetic observations for Group 4  
- `posterior4.csv` — Estimated posterior distribution corresponding to Group 4  

Each `data*.csv` file represents a synthetic opinion distribution treated as an empirical observation from a distinct online community. 

The corresponding `posterior*.csv` file contains samples from the estimated posterior distribution of the model parameters inferred using the BayesFlow pipeline.
